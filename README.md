# ForgePlayVP

Public privacy and support pages for the ForgePlay VR Vision Pro companion.

Website: https://facta-leopard.github.io/ForgePlayVP/

Support: https://github.com/Facta-Leopard/ForgePlay/issues

Free app, no ads. Requires Apple Vision Pro and a separate Apple Silicon Mac companion.

Languages: English, 한국어, 日本語, Español, Deutsch, Français, 简体中文, 繁體中文.

This repository contains website files only, not application source, signing credentials or archives.
