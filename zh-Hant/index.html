FORGEPLAY VR / VISION PRO

你的 Vision Pro。
你的 Mac。彼此相連。

ForgePlay VR 將 Mac 上執行的 VR 遊戲連接到 Apple Vision Pro。在這裡了解開始步驟、尋求協助，以及資料的處理方式。

支援↗隱私權↗
FP / VISION
免費 App無廣告需要 Apple 晶片 Mac
01

兩部裝置，一段體驗。

Vision Pro App 是配套 App，需要 Apple 晶片 Mac、獨立的 ForgePlayVR Mac App，以及相容的 Steam VR 遊戲。它無法只在 Vision Pro 上執行 Windows 版 Steam 遊戲。

02

準備好後，手動開始。

連接兩端 App，在 Mac 上啟動 Steam 和遊戲，再於 Vision Pro 開啟 VR 遊戲畫面。目前播放配置下，請在遊戲期間保持 Mac 虛擬顯示器連線。

03

App 本身免費。

Vision Pro App 免費且無廣告。硬體、Steam 帳號和遊戲需要另行準備。Mac 公開版本可在 GitHub 查看；遊戲相容性因遊戲而異。
