Game compatibility

For compatible Windows VR games on Steam that use DirectX 11 and OpenVR. DirectX 12 games are not supported, and some games with anti-cheat cannot run. The SteamVR system dashboard and separate overlay apps are not provided. Compatibility and supported controls vary even among DirectX 11 games.

Before you play

Choose hand tracking, a gamepad, or both. Pick the option that matches the controls your game supports.

  1. Install both apps

    Install ForgePlay on an Apple Silicon Mac and ForgePlayVP on Vision Pro. macOS 27 or later and visionOS 27 or later are required. The ForgePlay website below provides the Mac app and installation guide.

  2. Prepare Steam and a VR game

    For a first setup, we recommend installing Steam, signing in and preparing a compatible VR game in ForgePlay’s Mac view. You can also create a Steam environment in the VR view’s Steam setup using Windows SteamSetup.exe. If you already use Steam in ForgePlay, you do not need to install it again.

  3. Switch to VR and choose input

    Close Steam and games using the same environment, then choose VR in the launcher. Connect the existing environment in Steam setup. In Devices & Input, choose hand/gamepad mode and where the gamepad is connected before starting. To change these settings, stop Steam and disconnect the headset.

  4. Connect both devices

    Connect Mac and Vision Pro to the same local network, then connect Mac Virtual Display from Vision Pro. Prepare the Vision Pro connection in the Mac’s VR start view. Select that Mac in ForgePlayVP and enter the code displayed on it. Mac Virtual Display and ForgePlayVP are separate connections; keep both active during play.

  5. Launch the game in VR mode

    Choose Launch Steam in the Mac’s VR view and start a VR game in VR mode from Steam. Then tap ‘Open VR game screen’ on Vision Pro, including when the game is waiting for a headset. This does not convert ordinary games into VR games.

  6. Finish playing

    Save and exit the game, then end the session on Mac. Do not run the same Steam environment in Mac and VR modes at once. Folding or minimizing the window does not close the game.

Common questions

Can Vision Pro play on its own?

Requires ForgePlay on an Apple Silicon Mac and ForgePlayVP on Apple Vision Pro, with macOS 27 or later and visionOS 27 or later. Use a compatible Windows VR game from Steam and keep Mac Virtual Display connected during play. This does not convert ordinary games into VR games.

My Mac does not appear or pairing fails.

Open the Mac’s ForgePlay VR view and ForgePlayVP and check local network permission. For repeated authentication failures, reset pairing on both devices, then use Copy code on the Mac and paste the new code. Do not post the code publicly. For a brief disconnect, first allow automatic recovery to respond; report the timing and error text if failures recur.

The view stutters, disappears or stays on a waiting screen.

Keep Mac Virtual Display connected, verify that the game is running in VR mode on the Mac, and use the Vision app's VR-screen control to resume. Report whether the issue follows a scene change, head movement or Virtual Display disconnection. No game compatibility is guaranteed.

The microphone or hand input does not work.

Check the input mode, controller device and tracking permissions. Keep your hand visible, open it and fully release a pinch before trying again. If inward wrist rotation keeps snapping the pointer, report which hand and the motion sequence. Accuracy in every hand pose is not guaranteed. Enable the microphone only when needed; input and anti-cheat compatibility vary by game.

What should I include in a report?

Include both app versions, macOS/visionOS versions, Mac and Vision Pro models, the game, steps to reproduce and whether Mac Virtual Display was connected. Attach only reviewed, relevant diagnostics. GitHub posts are public.

Share your Steam prefix

The Mac and VR views in the unified ForgePlay app share one runtime and Steam environment. Steam, accounts, games and external libraries are not copied again. Close running Steam and games before switching modes.

Launch from the compact Dynamic Island

Switching to the launcher, Mac or VR view opens the Dynamic Island in its compact state. The compact VR Dynamic Island includes Launch Steam and Force stop Wine. The app icon on the right returns to the launcher. If fully collapsed to Fopl only, right-click Fopl to restore it. Folding, minimizing or closing the window does not end a session. Force stop can lose unsaved progress.

Game Mode status and Retina

VR uses DXMT. Game Mode is unavailable while compatibility is being improved; Steam and VR games run without it. High-resolution Retina defaults to off and can be changed after stopping Steam. Retina affects Mac Steam/game windows; VR video quality has its own setting.
