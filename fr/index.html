FORGEPLAY VR / VISION PRO

Votre Vision Pro.
Votre Mac. Connectés.

ForgePlay VR relie Apple Vision Pro aux jeux VR exécutés sur votre Mac. Retrouvez ici les premiers pas, l’assistance et les informations sur vos données.

FP / VISION
App gratuiteSans publicitéMac avec puce Apple requis
01

Deux appareils, une expérience.

L’app Vision Pro est un compagnon. Elle nécessite un Mac avec puce Apple, l’app ForgePlayVR pour Mac et un jeu Steam VR compatible. Elle n’exécute pas les jeux Steam Windows sur Vision Pro seul.

02

Préparez, puis lancez vous-même.

Connectez les apps, lancez Steam et le jeu sur le Mac, puis ouvrez l’écran du jeu VR sur Vision Pro. Dans la configuration actuelle, gardez l’écran virtuel du Mac connecté pendant la partie.

03

L’app est gratuite.

L’app Vision Pro est gratuite et sans publicité. Le matériel, le compte Steam et les jeux sont distincts. Les versions Mac disponibles figurent sur GitHub. La compatibilité varie selon le jeu.
