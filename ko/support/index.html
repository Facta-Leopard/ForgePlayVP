플레이 전 준비

VR맥앱의 ‘기기와 입력’에서 손·게임패드 모드와 패드 연결 위치를 먼저 선택하세요. Steam 실행 또는 기기 연결 후에는 이 선택이 잠깁니다. 변경하려면 세션을 종료하세요.

  1. Mac 준비

    별도 ForgePlayVR 맥앱을 설치합니다. 기존 ForgePlay Steam 환경을 공유하거나 VR맥앱에서 공통 Steam 환경을 새로 만듭니다. 데스크탑맥앱 설치는 필수가 아닙니다.

  2. Steam과 게임 준비

    Mac에서 Steam 설치·로그인을 마치고 호환되는 VR 게임을 설치합니다. 기존 환경을 공유한다면 데스크탑맥앱과 그 Steam·게임을 먼저 종료하세요.

  3. 기기 연결

    Mac 가상 디스플레이 연결을 유지합니다. 양쪽 VR앱을 열고 Vision Pro에서 Mac을 선택한 뒤 처음 연결할 때 페어링 코드를 입력합니다.

  4. 직접 플레이 시작

    Mac에서 Steam 실행을 누르고 게임을 VR 모드로 실행한 뒤 VisionPro앱에서 ‘VR 게임 화면 열기’를 누릅니다. 사용할 추적 권한을 허용하세요.

  5. 안전하게 마치기

    게임을 저장하고 종료한 뒤 VR 세션과 앱을 닫습니다. VR 세션이 실행 중인 Steam 환경을 데스크탑맥앱에서 동시에 사용하지 마세요.

자주 묻는 질문

Vision Pro만으로 실행할 수 있나요?

아니요. 별도 VR맥앱을 실행하는 Apple Silicon Mac이 필요합니다. 이 제품은 Windows·Linux PC를 호스트로 사용하는 방식이 아닙니다.

Mac이 안 보이거나 페어링이 실패해요.

양쪽 앱과 네트워크 상태, visionOS의 로컬 네트워크 권한을 확인하고 현재 페어링 코드를 사용하세요. 저장된 연결로 계속 실패하면 양쪽 앱에서 연결을 초기화한 뒤 다시 페어링하세요.

화면이 끊기거나 사라지고 대기 화면만 나와요.

Mac 가상 디스플레이 연결을 유지하고 Mac의 게임이 VR 모드인지 확인하세요. VisionPro앱의 VR 화면 버튼으로 재개할 수 있습니다. 장면 전환·머리 움직임·가상 디스플레이 종료 중 언제 발생하는지 알려주세요. 모든 게임의 호환성을 보장하지는 않습니다.

마이크나 손 입력이 안 돼요.

권한과 선택한 입력 모드를 확인하세요. 마이크는 필요할 때 켜면 됩니다. 손·컨트롤러 지원은 게임마다 다르며 안티치트 때문에 실행되지 않는 게임도 있습니다.

문제 제보에 무엇을 적나요?

양쪽 앱 버전, macOS·visionOS 버전, Mac·Vision Pro 모델, 게임 이름, 재현 순서, Mac 가상 디스플레이 연결 여부를 적어주세요. 필요한 진단만 개인정보를 검토한 뒤 첨부하세요. GitHub 게시물은 공개됩니다.
