Before you play

  1. Prepare your Mac

    Install the separate ForgePlayVR Mac app. Reuse an existing ForgePlay Steam environment, or create a new common Steam environment from the VR Mac app. The Desktop Mac app is not mandatory.

  2. Prepare Steam and a game

    Install or sign into Steam on the Mac and install a compatible VR game. When sharing an existing environment, close the Desktop Mac app, its Steam and its games first.

  3. Connect your devices

    Keep Mac Virtual Display connected. Open both VR apps, select your Mac on Vision Pro and enter the pairing code on the first connection.

  4. Start manually

    Press Steam launch on the Mac, start the game's VR mode, then choose Open VR game screen on Vision Pro. Allow the tracking permissions that you want to use.

  5. Finish safely

    Save and exit the game, end the VR session, then close the apps. Do not switch the same Steam environment to the Desktop Mac app while its VR session is running.

Common questions

Can Vision Pro play on its own?

No. This app streams from an Apple Silicon Mac running the separate VR Mac app. A Windows or Linux PC is not the host for this product.

My Mac does not appear or pairing fails.

Check that both apps are open, networking is available and local network access is allowed in visionOS. Confirm the current pairing code. If saved pairing remains unusable, reset the connection on both apps and pair again.

The view stutters, disappears or stays on a waiting screen.

Keep Mac Virtual Display connected, verify that the game is running in VR mode on the Mac, and use the Vision app's VR-screen control to resume. Report whether the issue follows a scene change, head movement or Virtual Display disconnection. No game compatibility is guaranteed.

The microphone or hand input does not work.

Check permissions and the selected input mode. Enable the microphone only if needed. Hand/controller support depends on the game; anti-cheat can also prevent some games from running.

What should I include in a report?

Include both app versions, macOS/visionOS versions, Mac and Vision Pro models, the game, steps to reproduce and whether Mac Virtual Display was connected. Attach only reviewed, relevant diagnostics. GitHub posts are public.
